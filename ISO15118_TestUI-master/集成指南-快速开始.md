# 🚀 C++测试程序集成 - 快速开始指南

## 📋 概述

本文档提供了将C++测试程序集成到ISO15118_TestUI项目的**最简单、最直接**的方法。

---

## 🎯 两种集成方式

### 方式1️⃣: 自动化集成（适合完整项目）
**使用场景**: 您有一个完整的C++测试套件项目

### 方式2️⃣: 手动集成（推荐快速开始）
**使用场景**: 您只有一个已编译的测试程序

---

## ⚡ 方式1: 自动化集成（一行命令搞定）

### 前提条件
- C++项目目录结构符合规范
- 包含CMakeLists.txt
- 测试用例注释格式正确

### 目录结构要求
```
YourCppProject/
├── CMakeLists.txt
├── TestCase/
│   └── src/
│       └── *.cpp（测试用例文件）
└── build/（自动生成）
```

### 执行步骤

```bash
# 1. 进入TestUI项目目录
cd ISO15118_TestUI-master

# 2. 一行命令完成所有集成
python manage.py initdb /path/to/YourCppProject
```

**就这么简单！** 🎉

该命令会自动：
- ✅ 编译您的C++项目
- ✅ 扫描测试用例
- ✅ 解析元数据
- ✅ 导入数据库

---

## ⚡ 方式2: 手动集成（3步完成）

### 第一步: 准备测试程序

确保您的测试程序：
- ✅ 可以独立运行
- ✅ 接受4个命令行参数
- ✅ 输出日志到stdout
- ✅ 返回exit code（0-4）

**测试程序示例**（参考 `examples/simple_test_example.cpp`）

### 第二步: 创建测试用例

#### 方法A: 使用集成脚本（推荐）

```bash
python integrate_test_program.py ./build/my_test MyTest_001 \
  --condition "测试条件描述" \
  --expected "期望结果描述" \
  --type CMN
```

#### 方法B: 使用Django Shell

```bash
python manage.py shell
```

```python
from testcase.models import TestcaseType
import os

tc = TestcaseType.objects.create(
    name="MyTest_001",
    type="CMN",
    status="n",
    build_status="OK",
    condition="测试条件",
    expected="期望结果",
    pics="{}",
    pixit="{}",
    path=os.path.abspath("./build/my_test")
)
print(f"创建成功: {tc.name}")
```

#### 方法C: 使用Web界面

```bash
# 启动Django服务
python manage.py runserver

# 访问 http://localhost:8000/admin
# 添加测试用例
```

### 第三步: 启动服务

```bash
# 启动后端
python manage.py runserver

# 启动前端（另一个终端）
cd frontend/testui
npm run dev
```

在浏览器访问 `http://localhost:8081` 即可看到并执行测试！

## 🔍 测试程序接口规范

### 必需的命令行参数

```cpp
int main(int argc, char* argv[]) {
    // argv[1] = 测试用例名称
    // argv[2] = 执行模式（通常是"I"）
    // argv[3] = V2G配置文件路径
    // argv[4] = SLAC配置文件路径
    
    std::string testcase_name = argv[1];
    std::string v2g_config = argv[3];
    std::string slac_config = argv[4];
    
    // 您的测试逻辑...
    
    return 1; // 返回测试结果
}
```

### 标准输出格式

所有日志输出到 `stdout`:

```cpp
std::cout << "测试开始..." << std::endl;
std::cout << "连接充电桩..." << std::endl;
std::cout << "测试完成" << std::endl;
```

### 退出码含义

```cpp
return 0; // none - 未执行
return 1; // pass - 通过
return 2; // inconclude - 不确定
return 3; // fail - 失败
return 4; // error - 错误
```

## 🆘 常见问题

### Q: "找不到测试程序文件"
**A:** 确保使用绝对路径或正确的相对路径

### Q: "测试用例没有显示"
**A:** 检查数据库：`python manage.py shell` → `TestcaseType.objects.all()`

### Q: "WebSocket连接失败"
**A:** 确保Redis服务运行：
```bash
# Linux
sudo systemctl start redis

# 检查
redis-cli ping  # 应该返回 PONG
```

### Q: "程序无法执行"
**A:** 检查文件权限：
```bash
chmod +x /path/to/your/program
```
