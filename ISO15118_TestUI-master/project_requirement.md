# 充电桩协议一致性测试平台 - 项目全局上下文 (Project Context)

## 1. 项目基本信息
* **项目名称：** 基于TTCN的充电桩协议一致性测试 
* **核心目标：** 针对新能源汽车充电网络协议碎片化、传统人工测试成本高的问题，基于 TTCN-3 和 ISO 15118 标准设计一致性测试系统，并利用大语言模型（LLM）实现测试用例的自动化生成。

## 2. 技术栈与系统架构
* **前端 (Frontend)：**Vue.js。负责测试管理界面、数据可视化以及与大模型的交互接口。
* **后端 (Backend)：**Python (Django)。负责提供 RESTful API，并通过 WebSocket 实现测试执行过程的毫秒级实时监控与数据同步。
* **测试执行引擎 (Test Engine)：** 基于 Eclipse Titan 的 TTCN-3 编译器与执行环境，运行于 Linux 虚拟机。
* **系统适配与编解码 (SA & Codec)：** 使用 C/C++ 结合 TTCN-3 的 TRI（测试运行时接口）规范开发。
* **协议栈要求：** 严格遵循 ISO 15118 国际标准，需处理底层 TCP/TLS 加密通道、V2GTP 消息头封装解析，以及 EXI/XML 数据流的高效序列化与反序列化。

## 3. 核心功能模块划分
### 3.1 Web 可视化与测试管理平台
* 设计符合 TCI（测试控制接口）标准的管理模块架构。
* 实现测试执行状态的实时监控，并将底层测试日志动态渲染为可视化的时序图（Sequence Diagram）。
* 支持多任务并发环境下的测试资源调度策略。

### 3.2 TTCN-3 协议适配与编解码模块 (底层核心)
* 解决抽象测试语言与具体通信协议栈（物理层到应用层）之间的映射与透明交互问题。
* 确保底层 C++ 适配器能精确控制并解析每一字节的通信数据。

### 3.3 ISO 15118 核心业务仿真
* 实现对握手、鉴权、参数发现等核心协议流程的仿真测试 [cite: 10]。
* 系统必须能够正确捕获网络报文，并自动判定测试用例的结果为 Pass 或 Fail。

### 3.4 LLM 自动化代码生成模块
* 构建“协议规范-代码对”指令数据集，对通用大模型进行特定领域微调。
* 输入自然语言测试意图，输出可编译执行且无语法错误的 TTCN-3 测试脚本。
* 重点确保大模型在生成 TTCN-3 特有语法（如 Template 定义、Altstep 状态机）时的准确性与逻辑连贯性。

## 4. 实验与验收标准
* 设计对比实验，选取至少 3 组典型测试场景。
* 记录并对比“传统人工编写脚本”与“基于 LLM 自动生成脚本”在开发耗时与代码覆盖率上的差异，通过实验数据量化展示系统的优越性。
