## Section A: Main Test Case Module

Generate ONLY the main test case module file:
`src/ttcn3/4_TestCases/{testcase_name}.ttcn`

The test case module structure:

```ttcn3
/**
 * @desc    [Test objective from generation plan]
 * @reference ISO 15118-2:2014, Section [X.X.X]
 * @requirement [V2G2-XXX]
 */
module {testcase_name} {

  // === Imports ===
  import from ISO15118_2_DataTypes all;
  import from ISO15118_2_Templates all;
  import from ISO15118_2_Functions all;
  import from ISO15118_2_Components all;
  import from ISO15118_2_PICS all;
  import from ISO15118_2_PIXIT all;
  import from ISO15118_2_Timers all;
  import from PreConditions_SECC_15118_2 all;
  import from PostConditions_SECC_15118_2 all;

  // === Test Behavior Function ===
  function {test_behavior_func_name}()
    runs on {component}
    return verdicttype
  {
    // 1. Start timer
    {timer}.start({timeout_param});

    // 2. Send stimulus
    {port_name}.send(/* message using send template */);

    // 3. Alt block
    alt {
      // Expected response
      [] {port_name}.receive(/* matching using receive template */) {
        {timer}.stop;
        setverdict(pass, "...");
      }
      // Unexpected response
      [] {port_name}.receive(?) {
        {timer}.stop;
        setverdict(fail, "...");
      }
      // Timeout
      [] {timer}.timeout {
        setverdict(inconc, "...");
      }
    }

    return getverdict;
  }

  // === Testcase ===
  testcase {testcase_name}()
    runs on {component} system {system_component}
  {
    var verdicttype preConVerdict;

    // Phase A+B: Pre Conditions
    f_SECC_CMN_PR_InitConfiguration_001();
    preConVerdict := f_SECC_CMN_PR_Binding_001();

    // Phase C: Test Behavior
    if (preConVerdict == pass) {
      {test_behavior_func_name}();
    } else {
      log("PreCondition verdict is not pass");
      setverdict(inconc);
    }

    // Phase D: Post Conditions (unconditional cleanup)
    f_SECC_CMN_PO_InitialState_001();
    f_SECC_CMN_PO_ShutdownConfiguration_001();
  }
}
```

## Section B: PreConditions and PostConditions Function Definitions

Based on the demo reference files, generate the following function definition files.
These functions implement the actual test setup (Phase A+B) and cleanup (Phase D).

### Key rules:

## Mode-Aware Generation (CRITICAL)
Based on the test mode (SIL vs HIL), generate DIFFERENT precondition/postcondition code.
The pipeline will inject the mode in the user prompt. Check for "## Test Mode" in the prompt.

**SIL Mode Rules**:
- f_SECC_CMN_PR_InitConfiguration_001: ONLY map mtc ports to system ports. NO PTC creation.
  - NO pt_HAL_61851_Port, NO pt_HAL_61851_Listener_Port, NO pt_SLAC_Port
  - NO v_HAL_61851_Listener variable, NO vc_SessionID, NO vc_eVCCID
  - Function signature: `f_SECC_CMN_PR_InitConfiguration_001()` -> no return
- f_SECC_CMN_PR_Binding_001: Log a message that SDP/TCP binding is simulated.
  - NO calls to f_SECC_CMN_PR_SDPDiscovery_001() or f_SECC_CMN_PR_TCPConnection_001()
  - Function signature: `f_SECC_CMN_PR_Binding_001()` -> return verdicttype (always pass in SIL)
- f_SECC_CMN_PO_InitialState_001: ONLY unmap mtc ports. NO PTC to stop.
  - Function signature: `f_SECC_CMN_PO_InitialState_001()` -> no return
- f_SECC_CMN_PO_ShutdownConfiguration_001: Log a message. NO TCP close message templates.
  - Function signature: `f_SECC_CMN_PO_ShutdownConfiguration_001()` -> no return

**HIL Mode Rules**:
- Full HAL_61851_Listener PTC creation and management
- Full SDP and TCP/TLS connection handling
- HAL61851Adapter integration

**Test Case Variables (SIL Mode)**:
- DO NOT declare `var HAL_61851_Listener v_HAL_61851_Listener`
- DO NOT pass v_HAL_61851_Listener to any function
- Only declare: `var verdicttype preConVerdict`

- Each function goes in its own .ttcn file with module name = function name
- f_SECC_CMN_PR_InitConfiguration_001: Creates HAL_61851_Listener PTC, maps all ports,
  starts HAL listener, initializes vc_SessionID and vc_eVCCID
- f_SECC_CMN_PR_SupportedAppProtocol_001: SDP discovery + TCP/TLS connection +
  sends SupportedAppProtocolReq + alt block with pass/fail/timeout verdict
- f_SECC_CMN_PO_InitialState_001: Stops HAL listener PTC, unmaps all ports
- f_SECC_CMN_PO_ShutdownConfiguration_001: Graceful TCP/TLS connection close
- PreConditions_SECC_15118_2: Aggregator module that imports all precondition functions
- PostConditions_SECC_15118_2: Aggregator module that imports all postcondition functions

```ttcn3
module f_SECC_CMN_PR_InitConfiguration_001 {

    function f_SECC_CMN_PR_InitConfiguration_001()

        // Map MTC ports to system ports (SIL mode: no PTC needed)
        map(mtc:pt_V2G_UDP_SDP_Port, system:pt_V2G_UDP_SDP_Port);
        map(mtc:pt_V2G_TCP_TLS_Port, system:pt_V2G_TCP_TLS_Port);
```

**f_SECC_CMN_PR_Binding_001.ttcn** (SIL mode):
```ttcn3
module f_SECC_CMN_PR_Binding_001 {
    import from SECC_TestSystem all;

    function f_SECC_CMN_PR_Binding_001()
    runs on SECCTester return verdicttype {
        var timer tc_V2G_EVCC_Msg_Timer := floattoint(PIXIT_CMN_Message_Timeout);

        // SIL mode: SDP/TCP binding is simulated by the port adapter
        log("SDP/TCP binding simulated in SIL mode");

        // Send SupportedAppProtocolReq
        tc_V2G_EVCC_Msg_Timer.start(PIXIT_CMN_Message_Timeout);
        pt_V2G_TCP_TLS_Port.send(
            md_CMN_V2GTP_Message_001(
                md_CMN_V2GTP_Header_001('01'O, 'FE'O, '8001'O, int2oct(payloadSize, 4)),
                md_CMN_V2GTP_Payload_001(
                    md_CMN_SupportedAppProtocolReq_001()
                )
            )
        );

        alt {
            [] pt_V2G_TCP_TLS_Port.receive(
                mw_CMN_V2GTP_Message_001(
                    mw_CMN_V2GTP_Header_001('01'O, 'FE'O, '8002'O, ?),
                    mw_CMN_V2GTP_Payload_001(
                        mw_CMN_SupportedAppProtocolRes_001(?)
                    )
                )
            ) {
                tc_V2G_EVCC_Msg_Timer.stop;
                setverdict(pass);
            }
            [] pt_V2G_TCP_TLS_Port.receive(?) {
                tc_V2G_EVCC_Msg_Timer.stop;
                setverdict(fail);
            }
            [] tc_V2G_EVCC_Msg_Timer.timeout {
                setverdict(inconc);
            }
        }

        return getverdict;
    }
}
```

## Critical Rules

### Naming Conventions (MUST follow exactly)
- testcase: Use the exact `testcase_name` from the generation plan (e.g. `TC_SECC_CMN_VTB_SupportedAppProtocol_001`)
  - DO NOT manually construct using TC_{SUT}_{Cat}_VTB_{Msg}_{Seq} — use the name from the plan
  - The testcase_name already includes the TC_ prefix, do NOT add another prefix
- test behavior: f_{SUT}_{Cat}_TB_VTB_{Msg}_{Seq}
- send template: md_CMN_{Msg}Req_{Seq}
- receive template: mdw_{SUT}_{Msg}Res_{Seq}
- module name = function name (e.g., module f_SECC_CMN_PR_InitConfiguration_001 { function f_SECC_CMN_PR_InitConfiguration_001(...) }

### Precondition Function Parameters (MUST follow exactly)
- f_SECC_CMN_PR_InitConfiguration_001() -> no return (SIL mode, no parameters)
- f_SECC_CMN_PR_Binding_001() -> return verdicttype (SIL mode, no parameters)
- If a precondition function returns verdicttype, you MUST store it in preConVerdict and check it before Phase C

### Postcondition Function Parameters (MUST follow exactly)
- f_SECC_CMN_PO_InitialState_001() -> no return (SIL mode, no parameters)
- f_SECC_CMN_PO_ShutdownConfiguration_001() -> no return (SIL mode, no parameters)
- PostConditions MUST be called regardless of preConVerdict value (Phase D runs unconditionally)

### Component and Port
- SECC tests: runs on SECCTester system SystemSECC, port pt_V2G_TCP_TLS_ALM_SECC_Port (internal) / pt_V2G_TCP_TLS_Port (mapped)
- EVCC tests: runs on EVCCTester system SystemEVCC, port pt_V2G_TCP_TLS_ALM_EVCC_Port (internal) / pt_V2G_TCP_TLS_Port (mapped)

### Timer
- EVERY alt branch that receives a message MUST call {timer}.stop BEFORE setverdict
- Timer timeout branch does NOT call stop (it already expired)

### Verdict Logic
- GoodCase: pass on valid response, fail on invalid, inconc on timeout
- BadCase: pass on rejection/close/timeout, fail on acceptance of invalid input

### V2GTP Header
- Always wrap V2G messages in V2GTP:
  - protocolVersion='01'O, invProtocolVersion='FE'O, payloadType='8001'O
  - payloadLength: MUST be a 4-byte octetstring, e.g. `int2oct(payloadSize, 4)`
  - DO NOT use 'omit' for payloadLength (it is not optional)

### Precondition/Postcondition Function Definitions
- The function DEFINITIONS (bodies) must be generated as separate .ttcn files (Section B above)
- Reference: demo's PreConditions/ and PostConditions/ directories
- Do NOT generate empty stubs — implement the actual logic per the demo reference
- Each precondition/postcondition function goes in its own .ttcn file with module name = function name
- The aggregator modules (PreConditions_SECC_15118_2.ttcn, PostConditions_SECC_15118_2.ttcn) import all individual functions

### Test Case Module
- The main TC_*.ttcn file MUST import from PreConditions_SECC_15118_2 and PostConditions_SECC_15118_2
- Phase A+B calls go at the beginning of the testcase body
- Phase D calls go at the end of the testcase body (unconditional)

### Documentation
- Add @desc, @reference, @requirement comments to the test case module
- Add inline comments for each phase and key operations
