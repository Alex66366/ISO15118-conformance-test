### HARD RULE #3 — JSON parsing: `match()` + `substr()` only

**TITAN string API reality** (verified 2026-07-18):
- `regexp()` and `indexof()` do **NOT** exist in TITAN. Calls like `regexp(json, "x") != -1` are **compilation errors**.
- `match()` is the only safe string-pattern API in TITAN.
- **TTCN-3 charstring literals use `""` (two consecutive double-quotes) to escape `"`, NOT `\"`** (backslash-quote). A `\"` in a `"..."` literal is **two literal characters: backslash + `"`**, NOT a single quote.

**✅ CORRECT `match()` pattern (use double-double-quote for escape):**
```ttcn3
// ISO 15118-2 ResponseCode format: OK_* or FAILED_* (underscore + suffix)
if (match(json, @nocase @"""*""""ResponseCode"""""":"""OK_""*""""""")) { resp_ok := true; }
```

**❌ WRONG (uses backslash, compiles but never matches):**
```ttcn3
if (match(json, "*\"ResponseCode\":\"OK_*\"*")) { ... }  // backslashes are literal, no match
```

### TB ResponseCode Validation (Mandatory in TB only, NOT in PR)

**For TestBody (TB) functions**: MUST validate `ResponseCode` before `setverdict(pass)`:

```ttcn3
// TB functions: validate ResponseCode from SECC response
[] pt_V2G_TCP_TLS_ALM_SECC_Port.receive({ raw := ? }) -> value v_msg {
    tc_msg.stop;
    var charstring resp_json := oct2char(v_msg.raw);
    var boolean resp_ok := false;

    // Validate ResponseCode using TTCN-3 pattern matching
    // NOTE: In TTCN-3 charstring literals, escape " by doubling it ("" not \")
    if (match(resp_json, @nocase @"*""ResponseCode"":""OK*""*")) { resp_ok := true; }
    else if (match(resp_json, @nocase @"*""ResponseCode"":""FAILED*""*")) {
        setverdict(fail, "SECC rejected the request"); return; }

    if (resp_ok) {
        log("Response valid, setting pass verdict");
        setverdict(pass, "Message exchange completed successfully");
    }
}
```

**For Precondition (PR) functions**: Do NOT validate ResponseCode. Extract session state only:

```ttcn3
// PR functions: extract session state and pass on valid raw response
[] pt_V2G_TCP_TLS_ALM_SECC_Port.receive({ raw := ? }) -> value v_msg {
    tc_msg.stop;
    var charstring resp_json := oct2char(v_msg.raw);
    log("Response received: ", resp_json);

    // NEW (v1.0): extract SessionID via helper -- NO hardcoded substr offset.
    // The helper is provided by Infrastructure Agent in SECC_CommonFunctions.ttcn
    // and applies the JSON-path-based semantic extraction from
    // generation_patterns.json -> semantic_extraction_rules.SessionID_extraction.
    var charstring sid_hex := f_extract_session_id(resp_json);
    if (lengthof(sid_hex) == 16 and sid_hex != "0000000000000000") {
        vc_SessionID := char2oct(sid_hex);
        log("SessionID extracted: ", sid_hex);
    }

    setverdict(pass, "Precondition exchange completed");
}
```

⚠️ **CRITICAL**:
- Never `setverdict(pass)` in a PR without receiving a valid raw response first.
- **NEVER** use `substr(resp_json, 39, 16)` — that offset is fragile and **DEPRECATED as of v1.0**. Use `f_extract_session_id()` helper instead.
