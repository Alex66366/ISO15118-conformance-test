## The V2G Message Exchange SOP (MANDATORY -- Read Before Writing Any Code)

**MECHANICAL SOP: Every V2G Application Message (SupportedAppProtocol through SessionStop)**

For EVERY V2G application message sent via TCP:

  STEP 1: Lookup JSON -- Read exi_payload_library.json. Record:
    - `wire_hex`: the canonical pre-encoded wire bytes (V2GTP header + EXI payload)
    - `is_dynamic`: if true, SessionID will be patched automatically by the C++ adapter

  STEP 2: Locate template -- Find `md_CMN_{Msg}Req_001` (send) and
    `md_CMN_{Msg}Res_001` (receive) in SECC_CmnTemplates.ttcn.
    Verify field values match the `json_payload` from step 1.

  STEP 3: Send via structured union ONLY -- The TCP port type is V2G_MessageUnion.
    The C++ adapter inside V2G_TCP_TLS_Port intercepts the union value,
    calls ExiCodecAdapter::encode() to look up the pre-encoded wire_hex,
    patches SessionID if needed, and sends the wire bytes over TCP.
    TTCN-3 code:
      pt_V2G_TCP_TLS_ALM_SECC_Port.send({ msgType := md_CMN_MsgReq_001 })

  STEP 4: Receive and set verdict -- Use matching structured template.
    The adapter logs a hex-dump of every sent/received frame.
    Stop timer before setverdict in non-timeout branches. End function with return getverdict.

**SDP messages ONLY (UDP port):** Use raw octetstrings.
  pt_V2G_UDP_SDP_Port.send('01FE9000000000021000'O) -- this is CORRECT for SDP.

### NEGATIVE CONSTRAINTS (MUST NOT -- Violations cause compile or runtime errors)

- MUST NOT use int2oct, '01'O, 'FE'O, '8001'O in TTCN-3 for V2GTP header construction
- MUST NOT send raw octetstrings to the TCP port for V2G application messages
- MUST NOT use openv2g encoder or X-Macro mapping -- ExiCodecAdapter handles encoding
- MUST NOT use V2G_MessageUnion with manual EXI encoding -- the adapter handles it

### V2G Message Types (Types_SECC_15118_2.ttcn)

The `SECC_Types` module in `Types_SECC_15118_2.ttcn` MUST define the following types:

1. **V2G_MessageUnion** -- the top-level union used as the port message type:
```ttcn3
type union V2G_MessageUnion {
    SupportedAppProtocolReq       supportedAppProtocolReq,
    SupportedAppProtocolRes      supportedAppProtocolRes,
    SessionSetupReq            sessionSetupReq,
    SessionSetupRes            sessionSetupRes,
    ServiceDiscoveryReq        serviceDiscoveryReq,
    ServiceDiscoveryRes        serviceDiscoveryRes,
    CableCheckReq              cableCheckReq,
    CableCheckRes              cableCheckRes,
    PowerDeliveryReq           powerDeliveryReq,
    PowerDeliveryRes           powerDeliveryRes,
    // ... all other V2G message body types
}
```

2. **Individual message types** (e.g., `SessionSetupReq`, `CableCheckReq`) must be defined as record types:
```ttcn3
type record SessionSetupReq {
    SessionIDType       sessionId,          // mandatory
    EvccIDType         evccId              // mandatory
    // optional: Notification (if used, set Notification_isUsed := 1)
}
```

3. The V2GTP port (V2G_TCP_TLS_Port) handles all EXI encoding/decoding internally using pre-encoded payloads from the JSON library (`exi_payload_library.json`). The C++ adapter calls ExiCodecAdapter::encode() to look up the pre-encoded wire_hex. The `V2G_MessageUnion` TTCN-3 type is used for compile-time type safety; at runtime, the port maps these to wire hex from the library.

### EXI Payload Library

Pre-encoded EXI payloads are stored in the JSON library at:
```
agent/test_code/examples/demo/exi_payload_library.json
```

Each entry contains:
- `wire_hex`: the complete V2GTP-wrapped wire frame (header + EXI payload)
- `is_dynamic`: whether the message has runtime-patched fields (e.g., SessionID)
- `json_payload`: the canonical JSON representation of the message (for reference)

Example usage in TTCN-3 templates:
```ttcn3
// CORRECT: Send via structured union template
// The ExiCodecAdapter in V2G_TCP_TLS_Port encodes to wire_hex automatically
pt_V2G_TCP_TLS_ALM_SECC_Port.send({ sessionSetupReq := md_CMN_SessionSetupReq_001 });

// CORRECT: Receive via matching structured template
pt_V2G_TCP_TLS_ALM_SECC_Port.receive({ sessionSetupRes := md_CMN_SessionSetupRes_001 });
```

module SECC_TestSystem {
